# 開發環境與隔離

更新：2026-10-28。比賽工作檔與Git分支隔離，但資料庫、App識別與服務設定仍須各自配置，不等於完整執行環境已隔離。

## 本機入口

```powershell
python tools/pipeline_dashboard.py
```

預設只綁定127.0.0.1:8787。預設不呼叫付費API，Search實驗區收合。已存照片範例依賴外層本機材料，新clone沒有範例時回傳404。

新Vision reader需要Python套件：FastAPI、uvicorn、Pillow、requests、python-dotenv、google-auth、google-genai、Pydantic2。設定`GOOGLE_APPLICATION_CREDENTIALS`指向本機服務帳戶、`GEMINI_API_KEY`於後端環境，再執行：

```powershell
python tools/reader_vision_competition.py
```

預設127.0.0.1:8181。既有EasyOCR reader入口為`tools/reader_competition.py`（8180）；切換新reader須明確設定Cloud的reader位址，不能同時假稱兩者都在同一請求執行。

接手機需可信任展示網路可達的儀表板位址，App以`EXPO_PUBLIC_PIPELINE_DASHBOARD_URL`選擇性回報；Cloud／reader以`PIPELINE_DASHBOARD_URL`選擇性回報。詳細步驟見[儀表板README](../web/pipeline/README.md)。尚未設登入的觀測器不應公開上網。
