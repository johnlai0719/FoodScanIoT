# 比賽版：本地雲端一鍵啟動

在專案根目錄雙擊 `start-cloud.bat`，或在 PowerShell 執行 `python tools/start_competition_cloud.py`。

腳本會依序檢查／啟動既有 PostgreSQL Docker 容器、Vision Reader（8181）、Cloud API（3003）。已符合預期健康狀態的服務直接沿用，不會重複啟動、停止其他程序或建立新資料庫。Docker Desktop 需先啟動；本機 Python 需已有專案依賴。

資料庫沿用 `app-sync-server-db-1` 與原有資料；不呼叫整套 compose，避免另外啟動一套 Cloud 或空資料庫。舊 Cloud 容器只讀取既有設定，不啟動。

沿用本機環境檔、既有 Cloud 容器中的共享金鑰與 GoogleCloudVision 憑證。金鑰只放在子程序環境，不寫入命令列或啟動器輸出。若更換電腦，需另行配置資料庫、Python 依賴與憑證。

Cloud 優先綁定目前 Tailscale IPv4；無法取得時只綁定 localhost 並提示。Pi 原先設定的 Cloud 位址仍須與此位址相符。可用環境變數 `COMPETITION_CLOUD_HOST` 明確指定綁定位址。

看到兩個服務顯示 ready 後即可使用。關閉啟動器視窗不會停止背景服務；重複執行可重新檢查。日誌及程序編號位於忽略追蹤的 `.artifacts/`。健康檢查不會實際呼叫 Google API，不能取代手機端辨識驗收。

此入口不啟動手機 App、Pi Fog 或儀表板；它們仍使用各自的啟動方式。
