#                    hand long ago -- rebuilding the venv would fail at startup.
#   - sqlalchemy     only used by database.py and models.py, which import nothing
#                    but each other and are used by no one. The cache actually runs
#                    on stdlib sqlite3 (Python) and better-sqlite3 (Node).
